# ASCEND Focus

Practice-based attention and mental discipline app, inspired by William Walker Atkinson's historical exercises.

See the [Master Blueprint](https://docs.google.com/document/d/1-9DXFFtHqUWGgSabES8yXlMARUYAB6MJi1TKX2lVkAw/edit) for curriculum, UX, privacy, community, and Codex instructions.

**Status:** initial scaffold. Community will remain a demo until a secure backend is deployed.

## Complete engineering specification

[ASCEND Focus Definitive Application Design & Engineering Specification v2](https://docs.google.com/document/d/16U1Rs7_o1CjWGCzHBDjXCB2-hjpxapimrF27x4Qhebk/edit) is the implementation contract: exercise registry, UX wireframes, neuroinclusive and motion behavior, domain state machines, AND/OR gates, feedback and matching algorithms, data flow, persistence, APIs, community roles, research integrity, tests and release gates.

**Truth in status:** the spec is a target design, not evidence that features are coded or tested. The original source PDF is kept in Drive, and access is not automatic. See [Atkinson source ledger](docs/ATKINSON-SOURCE-LEDGER.md).
